01 / INSTALL

A desktop client for everyone

Open the DMG and drag Taut to Applications. The same download works with every Taut server.

02 / CONNECT

Bring your server address

Enter the URL from your workspace administrator, or host your own instance. Your server runs the agents and stores your workspace.

03 / STAY CURRENT

Restart when you’re ready

Taut downloads desktop updates in the background. When an update is ready, choose “Restart to update.” Server upgrades stay with your administrator.
